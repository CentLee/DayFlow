# DayFlow Figma

Use this skill when producing or updating DayFlow UX/UI in Figma.

## Scope

- full MVP screen set
- wireframes and hi-fi designs
- design decisions must follow the product spec and budget board behavior

## Design Priorities

- the budget board is the product's signature screen
- one-screen editing is more important than decorative complexity
- calendar sharing should feel clear and lightweight
- use deliberate typography, strong spacing, and a non-generic layout

## Required Inputs

- `docs/product-spec.md`
- `docs/ios-architecture.md`
- `references/figma-deliverables.md`
